# 加密看板追踪器

汇总比特币资金面、宏观环境、链上估值与仓位情绪，支持中英文切换。

**[打开看板](https://hsnbrg2022.github.io/)**

## 使用方式

- 打开页面自动刷新一次，也可点击“刷新最新数据”。界面更新时间采用北京时间（UTC+8），各指标另标来源日期。
- 点击指标旁的信息图标查看解释；新访客默认中文，可切换英文。
- 仅 BTC ETF 资金流和多空比支持手工维护。ETF 可修改最近记录；多空比只需输入账户比和仓位比，仓帐比自动计算。
- 本地预览使用 http://127.0.0.1:4173/，需先启动服务；不支持直接打开 file:// 文件。

## 数据说明

- 看板混合使用接口行情、自动快照和手工记录。刷新成功不代表所有指标都是当日或实时数据，请以卡片来源、日期和状态为准。
- 链上估值无需 API Key：MVRV Z-Score 优先读取 OnChainLab 公开日值；失败或过期时，从 [Coin Metrics 免费基础数据](https://github.com/coinmetrics/data)计算经典 Z 值：已实现市值 = 市值 / MVRV，比对自2010-07-18起的完整连续日历史，用（市值 − 已实现市值）/ 市值历史总体标准差，未完日不参与。页面明确标记计算来源，快照保留公式、样本数和当日输入证据；该备用源按 CC BY-NC 4.0 署名，仅用于非商用看板，不冒充供应商直接发布的 Z 值。Puell Multiple 和 True Market Mean 读取 Checkonchain 公开图表的对应日值，TMM 不再用实时 BTC 价格或 AVIV 估算。后台每 4 小时检查，页面载入/刷新读取仓库最新快照，失败回退站点副本。只采用已完成 UTC 日；超过 3 天或采集失败保留旧值且如实标注。辅助 MVRV Ratio / SOPR 无可核验同日值时不展示，避免新旧口径混用。不同来源可能有实现差异，日频不等于秒级实时。
- ETF 后台在北京时间周二至周六 09:17、13:17、17:17 检查 PANews 的单日总流量报道，并读取 [Daily Market Report](https://www.dailymarket.report/index.html) 转述的 Farside 日流量作为免费备用（最多六页搜索加一次普通 GET，无需密钥）。即使主源可读也比较真实交易日，不把旧报道当最新。公开前端读取仓库快照，失败回退站点副本，不代表实时流量。每条自动记录保留原文链接和显示精度，DMR 标注 rounded；仅引用必要标量并署名回链，不复制图表或完整历史。缺日不补零，手工更正优先，来源失败保留旧值。同一原文的后续更正才允许更新自动值，其他金额冲突停止更新。定时任务可能延迟。
- mNAV 从 Strategy 免费官方 API 采集直接读数并校验公式、行情日期；公开刷新读取仓库最新快照，失败回退站点副本。资本资料独立保留原日期，不用行情日期替代；资料不完整或超过 7 天时，最新行情可展示，但不计入当期确认。采集失败保留旧值，不启用估算。
- mNAV 的“查看更新状态”分别显示行情日期、快照生成、前端读取结果及后台独立运行记录（UTC+8）。后台 `strategy-mnav-health.json` 包含真实检查、最近成功和脱敏错误分类；同值检查不翻新行情，失败保留旧值。页面择新读取仓库/站点记录，缺失或无效显示未知。所示状态仅代表读到的已发布记录，不保证此刻正常，也不代表资本资料已确认；未执行或取消的任务不生成新记录。
- 接口异常时保留最近值。过期或待核验指标不计入当期确认；有效覆盖不完整时，不作全局方向确认。
- ETF 免费采集仅接受严格验证的 SoSoValue / The Block 单日总流量句式，或 DMR 的 BTC 专属日流量卡片及交易日标签；拒绝错指标、非法/未来/未收盘日期、过旧或冲突值。卡片“查看更新状态”区分交易日期、快照生成、前端读取及后台采集，显示脱敏错误和区间缺日（支持中英文）。后台 `etf-flows-health.json` 缺失/无效时显示未知；采集成功不等于数据完整，同值检查不翻新快照时间，也不保证最新交易日已公布。手工记录不覆盖，后台完整性不验证浏览器手工覆盖。

## 隐私与保存

- 公开版手工记录和语言选择仅保存在当前浏览器，不写回 GitHub、不影响其他访客，也不会自动跨设备同步。
- 清理浏览器站点数据可能丢失个人记录，请自行留存重要内容。
- 本地维护版保存后需发布，其他访客才能看到变更；不要向公开仓库或浏览器前端写入任何访问凭据。
- 本地页面先核验服务的维护能力与请求保护，再启用后端保存；普通静态预览、旧服务或探测失败采用浏览器个人保存并隐藏后端快照按钮，不因 localhost 地址而认定存在后端。旧本地服务需重启以支持新能力接口；GitHub Pages 不探测本地接口。
- 本地服务启动后，首屏先读取本地 ETF 快照；页面自动刷新或手动刷新会下载同一公开仓库快照并缓存，无需密钥或电脑常驻采集。断网保留旧值，本地手工更正不会被覆盖。获取快照不等于重新采集上游数据。
