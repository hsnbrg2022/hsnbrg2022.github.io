# 加密看板追踪器

汇总比特币资金面、宏观环境、链上估值与仓位情绪，支持中英文切换。

**[打开看板](https://hsnbrg2022.github.io/)**

## 使用方式

- 打开页面自动刷新一次，也可点击“刷新最新数据”。界面更新时间采用北京时间（UTC+8），各指标另标来源日期。
- 点击指标旁的信息图标查看解释；新访客默认中文，可切换英文。
- 仅 BTC ETF 资金流和多空比支持手工维护。ETF 可修改最近记录；多空比只需输入账户比和仓位比，仓帐比自动计算。
- 本地预览使用 http://127.0.0.1:4173/，需先启动服务；不支持直接打开 file:// 文件。

## 数据说明

- 看板混合使用接口行情、自动快照和手工记录。刷新成功不代表所有指标都是当日或实时数据，请以卡片来源、日期和状态为准。
- MVRV Z-Score 与 Puell Multiple 使用官方日值；公开版读取自动快照，后台每 4 小时检查更新。超过 3 天的读数保留展示，但不计入当期确认。
- ETF 后台在北京时间周二至周六 09:17、13:17、17:17 检查 PANews 转述的 SoSoValue 单日总流量，免费、无需密钥。公开前端读取仓库最新快照，失败时回退站点副本，不依赖每次重新部署 Pages，也不代表实时流量。媒体数值可能经过四舍五入，每条自动记录保留原文链接及精度。历史补查最多六页，缺日不补零；手工更正优先，来源失败保留旧值。同一原文的后续更正才允许更新自动值，其他金额冲突停止更新。定时任务可能延迟。
- mNAV 从 Strategy 免费官方 API 采集直接读数并校验公式、行情日期；公开刷新读取仓库最新快照，失败回退站点副本。资本资料独立保留原日期，不用行情日期替代；资料不完整或超过 7 天时，最新行情可展示，但不计入当期确认。采集失败保留旧值，不启用估算。
- mNAV 的“查看更新状态”区分行情日期、快照生成与前端检查/读取结果（时间为 UTC+8）。后台最近检查、成功采集和失败原因的独立记录尚未接入，会明确标注；读取快照成功不等于上游采集成功。
- mNAV 后台另存 `strategy-mnav-health.json`，记录真实采集检查、最近成功及脱敏错误分类。同值检查不翻新行情快照；失败保留行情与最近成功时间，工作流仍报错。此记录尚待接入页面，不代表资本资料已核验；未执行或被取消的任务不会生成新记录。
- 接口异常时保留最近值。过期或待核验指标不计入当期确认；有效覆盖不完整时，不作全局方向确认。

## 隐私与保存

- 公开版手工记录和语言选择仅保存在当前浏览器，不写回 GitHub、不影响其他访客，也不会自动跨设备同步。
- 清理浏览器站点数据可能丢失个人记录，请自行留存重要内容。
- 本地维护版保存后需发布，其他访客才能看到变更；不要向公开仓库或浏览器前端写入任何访问凭据。
- 本地服务启动后，首屏先读取本地 ETF 快照；页面自动刷新或手动刷新会下载同一公开仓库快照并缓存，无需密钥或电脑常驻采集。断网保留旧值，本地手工更正不会被覆盖。获取快照不等于重新采集上游数据。

## 开发验证

使用 Node.js 20 或以上版本，在仓库根目录运行 `npm test`，无需安装依赖或配置凭据。当前 55 项公开测试覆盖 ETF 免费媒体解析、补查、更正保护与仓库快照读取，以及每日基线、个人维护、交易日历、稳定币、TMM、200WMA、黄金、mNAV 官方 API 与资本确认分离、更新状态展示、刷新与发布安全；其余回归测试尚未迁入。

GitHub Actions 的 `Public tests` 在推送 main 或提交面向 main 的 PR 时自动运行测试与发布清单校验，也支持手动运行。仅使用只读权限，不采集或修改行情；当前不阻断 Pages 部署，尚未配置必需检查或分支保护。
